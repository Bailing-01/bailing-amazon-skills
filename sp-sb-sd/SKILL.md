# SP/SB/SD 广告活动架构搭建

## 目标
按「一个活动只干一件事」搭可归因的广告骨架，让探索、收割、防守、定投、再营销预算互不污染。

## 前置确认
1. 产品阶段：新品期 / 成长期 / 成熟期。
2. 是否品牌备案（Brand Registry）→ 决定能否开 SB / SD。
3. 日预算总额、售价、毛利率粗估、库存可售天数。
4. 推广 ASIN 是否有黄金购物车（Featured Offer）。

## 步骤

### 1. 定分工（角色表）
| 类型 | 角色 | 典型预算带（起步参考） |
|------|------|------------------------|
| SP 自动 | 发现搜索词 + 关联 ASIN | 新品 ~25–30%；成熟 ~10–20% |
| SP 手动精准 | 已验证转化词收割 | 新品 ~35–45%；成熟 ~40–55% |
| SP 手动词组/广泛 | 二次扩量 / 长尾 | ~15–25% |
| SP 商品定投 | 竞品/互补 ASIN 拦截 | ~5–15% |
| SB | 品牌词防守 + 品类曝光 / 视频 | 有备案后 ~10–25% |
| SD | 浏览未购 / 已购再营销 + 上下文定投 | 成熟后 ~10–18% |

> 无品牌备案：先做纯 SP 四层，不要在方案里硬塞 SB/SD。

### 2. 新品期模板（先跑词后收割）
同时至少开：**SP Auto + SP Exact**（不要只开自动）。
- L1 探索：SP Auto；四个定向组分开设价（close match 正常价，loose / substitutes / complements 压低）。
- L2 收割：SP Manual Exact（承接已出单词）。
- L3 扩量：SP Manual Phrase（可选 Broad）。
- L4 定投：SP Product Targeting（竞品 ASIN / 相关类目）。

### 3. 成熟期模板（守盘 + 挤对手）
保留四层，但下调 Auto 权重；补：
- 品牌防守：SB 品牌词 + SP Exact 品牌词（小额常开）。
- 竞品层：SP ASIN 定投（优先：评分更低 / 价格更高 / 评论更少的可打对象）。
- 再营销：SD Views 与 SD Purchases **拆成独立活动**（勿混）。

### 4. 命名规范（固定字段顺序，中途勿改）
```
广告类型-投放方式-匹配/定向-产品简称-用途标签
```
示例：
- `SP-Auto-ALL-{SKU}-探索`
- `SP-Manual-Exact-{SKU}-收割`
- `SP-Manual-Phrase-{SKU}-扩量`
- `SP-PT-ASIN-{SKU}-竞品定投`
- `SB-KW-Exact-{Brand}-品牌防守`
- `SD-Aud-Views-{SKU}-浏览再营销`

### 5. 结构验收清单
- [ ] 每个活动只有一个主任务（探索 ≠ 收割）
- [ ] 同一搜索词不会同时在 Auto 与 Exact「双开」竞价（靠否定桥接）
- [ ] 预算占比合计 100%，且收割层不被探索层饿死
- [ ] 命名可筛：能一键滤出所有 Exact / 所有定投
- [ ] 库存可售天数足够支撑当前日预算

### 6. 输出给用户的交付物
1. 分层方案表（层级 | 类型 | 任务 | 日预算金额+占比 | 观察指标）
2. 活动/广告组命名表
3. 迁移规则一句话：何时把词从探索提到收割（见 `search-term-harvest-negate-loop`）

## 常见错误（直接纠正）
- 一个活动塞几十～上百无关词
- Auto 吃大头、Exact 饿着
- 无品牌防守，品牌词被竞品白嫖
- 新品结构套到成熟期不调权重

## 不适用
- 搜索词份额/帕累托深度报告 → 用既有 search-term share 分析技能
- Cerebro / ABA 词库建设 → 用既有 Cerebro / ABA 技能
