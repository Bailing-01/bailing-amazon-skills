# 亚马逊 Listing 文案撰写

严格按五步顺序执行，上一步产物齐全后才能进入下一步。禁止跳过采数直接写稿。本岗只出草稿，不发布、不写领星、不登录 Seller Central。

## 输入与产出

输入（缺一项先要，不猜）：本品实物参数与卖点（立项 / 工厂，不得虚改容量、成分、规格）、站点、品类、品牌；竞品 ASIN 若已有可直接给。

产出（一套五件，落本地路径，版本并排；回复只给路径和摘要）：

1. 竞品信息表（ASIN、品牌、标题、五点、长描、其他可见属性）
2. 核心词表 + 品牌词排除清单
3. Listing 草稿（标题、五点、长描、Search Terms 及后台属性）
4. 关键词覆盖核对表（已覆盖 / 未覆盖）
5. Alexa 问答摘要与补入说明

## 硬规则

- 实物参数以立项和工厂为准，缺字段写「无数据」，不编造。
- 竞品品牌词（含品牌名与品类拼在一起的词）不得出现在标题、五点、描述、Search Terms 和后台属性里。
- 不医疗宣称、不夸效；写完先过风控词库，再交运营验收。
- 长描用 `<br>` 换行、`<b>` 加粗（亚马逊不会自动换行和加粗）。
- 批量采数或收补可交 Codex 跑，但五步不得省。

## 第 1 步 采集竞品数据

优先用卖家精灵 MCP 抓取；没有再退到领星或 Helium 10。

选与本品品类、用途高度相关的头部产品（通常 5–10 个）。每个竞品必采：ASIN、品牌、标题、五点、长描，以及前台能看到的其他全部信息（类目、变体、价格、评分、主要属性、A+ 可见文字等）。

产物：竞品信息表。没有这张表不得进入第 2 步。

## 第 2 步 Helium 10 反查核心词

用 Helium 10 Cerebro 对第 1 步竞品 ASIN 反查。取自然排名靠前的词，按搜索量 / 关键词销量降序。

默认保留关键词销量大于 3,000 的词作为核心候选；若品类整体搜索量偏低、达标词过少，下调阈值并写清原因。

检查输出时必须单独标出品牌词（竞品品牌名出现在词组里的，例如「品牌名 + 品类词」）：这些词进「品牌词排除清单」，不进核心词表。

产物：核心词表、品牌词排除清单。没有这两份不得进入第 3 步。

## 第 3 步 结合本品卖点与差异化撰写

输入三块：竞品标题 + 五点（参考结构与表达，不照抄）、第 2 步核心词（已剔除品牌词）、本品特殊卖点与差异化（只用已给定的事实）。

写四部分：

1. **标题**：SEO 且自然流畅，核心词优先覆盖，不堆砌。
2. **五点**：条理清晰、有说服力；关键词放在每条**前半句**。
3. **长描**：目标市场地道表达，可有情感共鸣但不虚夸；用 `<br>`、`<b>`。
4. **后台属性草稿**：Search Terms（不含品牌词）、`item_type_keyword`、`target_audience_keyword`，以及能从数据得出的 `used_with` 等字段。

语气随品类调整，不要套用固定的美妆口吻。写完做关键词覆盖核对：第 2 步核心词须自然出现，列出已覆盖与未覆盖。本品特殊卖点若未写入，先重写补入，再进下一步。

## 第 4 步 排除竞品品牌词（第二遍强制检查）

对标题、五点、长描、Search Terms、后台属性全文再搜一遍：第 2 步品牌词排除清单，加上竞品品牌名本身。任何命中都必须改掉，才能进入第 5 步。

## 第 5 步 Alexa 问答调研，出终稿

针对本品类和核心竞品，收集 Alexa（原 Rufus）仍在问的问题，以及竞品页面上给出的答案。按下面 15 类整理：

1. 使用目的 / 用来做什么（Purpose / Function）
2. 使用场景 / 活动（Scene / Event）
3. 使用人群 / 用户画像（Audience / User）
4. 能力与效果（Capability / Benefit）
5. 功能拆解（Features）
6. 基础属性 / 类型（Attribute / Type）
7. 使用时间 / 频率（Time）
8. 使用地点（Location）
9. 使用对象 / 搭配对象（Used For / Used With）
10. 同时使用商品（Bundle / Pairing）
11. 用户喜欢的点（Likes / Pros）
12. 用户不喜欢的点（Dislikes / Cons）
13. 替代选择（Alternatives）
14. 兴趣与需求延展（Interest / Want）
15. 购买动机（Buying Intent）

同时关注 COSMO 关系，尤其是 **used_with（与谁搭配）**、使用场景和人群——这些既影响销售，也影响 Alexa 如何回答。

对照本品文案：竞品已被问到而本品文案未覆盖的问题，用**真实卖点**补进标题 / 五点 / 描述 / 属性；没有事实依据的不编造。

出终稿后，再跑一遍第 4 步品牌词检查和关键词覆盖表。然后过风控词库，交运营验收。
