# 商业知识 MG 动画

## 已确认的制作偏好

- 保留用户选定的音乐、风格和画幅。未得到新指示时，不擅自将原音乐换成合成曲，不改成长篇口播。用户指定原曲时继续制作，并如实记录来源与授权状态。
- 本系列默认黑底琥珀金、无口播、约90秒横屏1920×1080/30fps。时长和画幅以当前任务为准；品牌标识只在用户要求时添加。
- 精确图文用代码绘制：Remotion、Canvas、HyperFrames 或合适的现有工程均可。不要把“用了代码”笼统说成“用了Remotion”；注明实际引擎。生成式视频只适合不承载公式与数据的空镜。
- 交付文件不等于授权发布；付费调用需要该次任务的授权。总结发给其他bot、提交GitHub也以用户当前授权范围为准。

## 先把结论算对

确认每个成本、费率、销售额的口径；示意数值直接标为教学示意，无数据不编造。数值与图形共用同一份数据。

涉及定价、利润、ACoS、TACoS时，读 [pricing-and-profit.md](references/pricing-and-profit.md)，可运行 `python3 scripts/pricing_model.py` 验算。区分单件利润、利润率、总利润、销量倍数，不能用一个曲线代替它们。

## 镜头必须表达变化

1. 用真实的卖家疑问或可验算的反差开场。例如“跨境电商卷价格，真的有意义吗？”配“降价10%，销量需增加约67%才能赚回原利润”。数字须有相应假设。
2. 每镜写出“元素—动作—结果”；条形增长、亏损跌破零线、价格下降导致销量倍数陡增，都要真的发生在画面里。背景粒子、呼吸缩放、卡片闪烁不能代替主信息动画。
3. 文字按信息单位逐步出现，像动画PPT或字幕。短句、标签、金额和结论绑定各自拍点；不可开场整屏文字铺满后等待，也不必让图表刻度和固定页码一直动。
4. 柱子新增一段时，对应费用名、金额、引导线同步出现。不要先显示所有标签，再只让左边的柱子增长。
5. 公式按“变量 → 关系 → 代入 → 正确结果 → 解释”渐进揭示。结果可晚出现；不要为了数字滚动，在等号后显示数学上错误的中间值。
6. 图表的演示方向服从叙事：讲涨价脱离亏损时，从低价亏损穿过零线到盈利；讲价格战时，从高价/1倍销量走向低价/高倍数，而非反向画曲线。

## 配乐、音效和动作共用时间表

- 先分析当前使用的实际音轨，不把历史BPM当作已验证事实。可用librosa或频谱通量；检查半拍/倍拍歧义、强起音与段落变化。算法峰值不等于人工确认的听感。
- 建立统一事件表：时间、帧号、文字单元、图形状态、揭晓、转场、音效。最后才按 `round(seconds × fps)` 转帧；记录实际取整误差。
- 新元素/句子跟拍出现，核心反转与结果落重拍。音效使用同一事件表；轻音效服务动作，不覆盖原曲。不随意变速原音乐。
- 不把“拍点数据对齐”“无解码错误”说成“人工听感已通过”。必须查看导出视频的变化过程；仅看单张完成态无法发现字幕提前或费用标签早出。

## 排版与强调

- 分段出现的公式仍作为完整的一行排版：先测完整字符串宽度、整体居中，再把每段放到累计字宽的位置；不要分段各自居中在画面两侧。1920宽下，段间18–20px可作起点，随字号调整。
- 重点结论用更亮、更粗、更大的文字强调。例如“单件利润少40%”单独亮金粗体，明显强于“售价降10%”。轻发光不能损伤阅读。
- 检查动画全过程的包围盒，不仅检查最终静帧。负利润柱向下伸展时，结论移到图形最大范围之外，留足字幕空间。
- 在接近手机播放尺寸的缩略图上检查字号、对比、间距。不要把全部文字都加亮；主信息保持层次。
- 具体实现与逐镜验收参见 [motion-and-layout.md](references/motion-and-layout.md)。

## 验收与复用

新方向先出关键静帧和短样片；已确定方向按授权完成全片，不为重复的例行检查强加审批。每次修订围绕实际反馈，保留已接受的音乐、结构和正确计算。

交付前检查：公式和数值；各镜进入/中间/结束帧；成本标签与柱段同步；负值和极端值遮挡；分段公式最终拼接；正文分步出现；原曲与动作事件匹配；完整音视频解码、规格和时长。报告实际完成的检查及剩余限制。

交付成片、可选短预览、封面/文案、可复用源代码和必要来源说明。用户明确要总结时，追踪“需求 → 输入 → 各版输出 → 修正 → 接受版本”，不能仅凭读过文件就声称学会。
