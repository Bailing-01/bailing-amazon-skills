# 步骤 6：周期对比分析（V2 新增）

- **输入**：当前周期Excel路径 + `--excel-prev` 上一周期Excel路径
- **依赖**：S1-S3（当前周期数据已产出）
- **操作**：运行 `scripts/run_analysis.py --excel <当前> --excel-prev <上周期> --step all`，脚本自动读取上一周期数据并调用 `compare_periods()` 计算两周期的变化
- **输出**：JSON中增加 `period_comparison` 字段，包含：
  - `overall`：产品级总花费/订单/CVR/ACOS/CPC的before-after对比
  - `top4_comparison`：头部4%核心词的份额/排名/CPC/ACOS/订单 before-after对比
  - `new_keywords`：当前周期新增的搜索词（上周期无）
  - `lost_keywords`：上周期有但当前消失的搜索词
  - `share_up`/`share_down`：份额提升/下滑Top10
  - `rank_up`/`rank_down`：排名提升/下滑Top10
  - `acos_worse`/`acos_better`：ACOS恶化/改善Top5
  - `stats`：各类统计计数
- **用途**：进入报告"模块三：周期对比分析"章节（编号十三~十五）

判定阈值：份额变化>1%=显著、排名变化>3位=显著、ACOS变化>10%=显著
