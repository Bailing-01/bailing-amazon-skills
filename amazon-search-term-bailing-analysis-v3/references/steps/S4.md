# S4: 生成报告

## 输入
- S2 输出的 `data/structure_data.json`（模块一数据）
- S3 输出的 `data/search_terms_data.json`（模块二数据）

## 依赖
- S2, S3

## 操作
1. agent 读取 S2 和 S3 的 JSON 数据，基于数据内容编写 HTML 片段
2. HTML 片段结构（从 `.report-header` 到 `.report-footer`）：
   - **模块一：广告结构分析**（编号一~六）
     - 一、报表结构总览：组合数/活动数/投放数/搜索词数/花费/订单/CVR
     - 二、按产品拆分广告活动层对比：CVR/CPA/花费占比
     - 三~五、投放层 Top N 详情
     - 六、活动/投放层级行动建议
   - 模块分隔标题（绿色边框）
   - **模块二：关键词分析**（编号七~十二）
     - 七、帕累托分析：前20%/4%核心词订单贡献占比
     - 八、头部4%核心词详表
     - 九、份额分级
     - 十~十一、长尾80%分类归组（7类）
     - 十二、搜索词维度行动建议
3. 将 HTML 片段写入文件
4. 调用 `linkfox-report-generator` 的 `inject_report.py` 注入模板：
   ```bash
   python <report-generator>/scripts/inject_report.py \
     --content-file <html_fragment_file> \
     --language zh \
     --title amazon-ad-complete-analysis
   ```
5. 报告落盘到 session reports 目录

## 输出
- 最终 HTML 报告文件（绝对路径）

## 用途
- 最终交付物，供 S5 输出给用户
