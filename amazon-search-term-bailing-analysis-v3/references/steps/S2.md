# S2: 结构提取

## 输入
- S1 输出的 `data/extracted_data.json`

## 依赖
- S1

## 操作
1. 运行 `scripts/run_analysis.py --step structure`
2. 读取 S1 的输出 JSON，按广告组合(Portfolio) → 广告活动(Campaign) → 投放(Target) 三级聚合
3. 每级计算汇总指标：
   - 花费(spend)、点击(clicks)、订单(orders)
   - CVR = 订单 / 点击
   - CPA = 花费 / 订单
   - CPC = 花费 / 点击
   - 花费占比 = 该层级花费 / 总花费
4. 广告组合层：输出组合数、活动数、投放数、搜索词数、总花费、总订单、整体 CVR/CPA
5. 广告活动层：每个组合下钻到活动，输出活动名、投放数、搜索词数、花费占比、CVR、CPA、匹配类型
6. 投放层：每个活动下钻到投放 Top 20，输出投放名、搜索词数、花费、点击、订单、CVR、CPA
7. 按 CVR 基准评价每个活动和投放：
   - CVR >= 15% → 优秀(绿)
   - 12% <= CVR < 15% → 正常(蓝)
   - 8% <= CVR < 12% → 临界(橙)
   - CVR < 8% → 偏低(红)

## 输出
- `data/structure_data.json`：结构化三级聚合数据（portfolio 列表 → campaign 列表 → target 列表，含指标与评价）

## 用途
- 进入报告「模块一：广告结构分析」章节（编号一~六）
