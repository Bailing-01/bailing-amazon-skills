# S3: 搜索词聚合

## 输入
- S1 输出的 `data/extracted_data.json`

## 依赖
- S1

## 操作
1. 运行 `scripts/run_analysis.py --step search_terms`
2. 读取 S1 输出 JSON，按产品(广告组合) + 搜索词维度聚合
3. 帕累托分析：
   - 搜索词按订单降序排列
   - 计算头部前20%（`int(n * 0.20)`）和前4%（`int(n * 0.04)`）的订单贡献占比
   - 头部4%核心词详表：搜索词/订单/占比/CVR/份额/排名/市场量/花费/CPA + 份额评价 + CVR评价
4. 份额分级（按 avg_share 分档）：
   - >= 10% → 非常好
   - 5% ~ 10% → 好
   - 1% ~ 5% → 有声量
   - < 1% → 弱
5. 长尾80%分类归组（7类）：
   - `1_出单长尾`：orders > 0 且 CVR >= cvr_normal(默认0.12)
   - `2_有点击无转化`：orders = 0 且 clicks > 0
   - `3_有曝光无点击`：clicks = 0 且 impressions > 0
   - `4_高份额小市场`：share >= share_good(默认0.05) 且 market < 500000
   - `5_品牌竞品词`：搜索词含品牌关键词（硬编码列表）
   - `6_低相关泛词`：不属于以上任何分类的其余词
   - `7_零曝光僵尸词`：impressions = 0 且 clicks = 0
6. 识别核心词类型：根基词(CVR优秀+份额好)、大市场低份额词、效率短板词(CPA远高于均值)

## 输出
- `data/search_terms_data.json`：每个产品的帕累托结果、份额分级、长尾分类

## 用途
- 进入报告「模块二：关键词分析」章节（编号七~十二）
