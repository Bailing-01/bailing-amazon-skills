## 这个 Skill 做什么

亚马逊 SP 广告搜索词展示量份额报告全流程分析 V3：广告结构 + 搜索词帕累托 + 多周期对比（周期对比为核心功能）。  
支持双周期份额变化、排名升降、新增 / 消失关键词、ACOS 趋势对比；V3 新增 C2 长尾深度分析（点击次数分布 + 词根关联分析）。

## 怎么用

触发词：搜索词份额分析、展示量份额报告、多周期对比、份额变化、排名趋势、搜索词Bailing分析；或直接说“对比分析这两份广告报表”

安装：把本文件夹复制到你的 Agent skills 目录即可（完整说明见 `SKILL.md`）。

```bash
git clone https://github.com/Bailing-01/bailing-amazon-skills.git
# Claude Code；Codex / Hermes 等换成对应的 skills 目录
cp -r bailing-amazon-skills/amazon-search-term-bailing-analysis-v3 ~/.claude/skills/
```
