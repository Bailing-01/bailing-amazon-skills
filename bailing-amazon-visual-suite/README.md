## 这个 Skill 做什么

Bailing 亚马逊主副图 A+ 4.0：根据产品图、卖点、Listing、竞品链接或参考图，一次生成整套亚马逊图片。  
包括 1 张方形主图、6 张方形副图、7 个桌面端 A+ 模块和 7 个移动端 A+ 模块。

## 怎么用

触发词：Bailing亚马逊主副图A+4.0、Bailing亚马逊主副图A+、亚马逊整套图片、主图副图A+一次性生成、Amazon main images / secondary images / A+ modules

安装：把本文件夹复制到你的 Agent skills 目录即可（完整说明见 `SKILL.md`）。

```bash
git clone https://github.com/Bailing-01/bailing-amazon-skills.git
# Claude Code；Codex / Hermes 等换成对应的 skills 目录
cp -r bailing-amazon-skills/bailing-amazon-visual-suite ~/.claude/skills/
```
