# Quality Rules

## Product Truth

- Preserve product silhouette, proportions, colorway, material look, logo, label, pattern placement, structure, parts, accessories, and packaging facts.
- Do not invent extra parts, alternate SKUs, certifications, awards, ratings, reviews, sales numbers, rankings, test results, or endorsements.
- Keep physical logic credible: contact, shadow, scale, perspective, occlusion, hand grip, wearing fit, opening direction, and gravity.

## Main Image Compliance

- Main image must use a real product source image.
- Use a white background and no lifestyle context unless the user explicitly targets a category/platform rule that allows otherwise.
- Do not add text, icons, badges, props, fake accessories, comparison labels, or unsupported packaging.
- If the source image cannot support a compliant main image, stop that asset and request a better image while continuing non-main planning if useful.

## Copy And Claims

- Use marketplace language: Amazon US defaults to English; follow the site when specified.
- Keep on-image copy short, natural, and shopper-facing.
- Avoid absolute and risky claims such as best, No.1, guaranteed, permanent, medical treatment, 100% waterproof/leakproof, certified, FDA, CE, BPA-free, eco, organic, or lab-tested unless user provides evidence.
- Downgrade unsupported points to conservative wording or keep them off-image.

## Visual Quality

- Each image must communicate its selling point visually before text is read.
- Avoid generic AI ecommerce templates, busy card grids, random glow, fake badges, tiny dense labels, unreadable text, and repeated layouts.
- Across the secondary and A+ sets, use varied composition: hero, scene, macro, structure, comparison, use process, package, scale, and recap.
- No more than three images in the full selling set may share the same large-product-plus-top-title layout.

## QA Checklist

Before delivery, check:

- Correct file count: 1 + 6 + 7 + 7.
- Default final count is exactly 21/21; 6 A+ images alone is a failed partial execution, not a valid completion.
- Correct dimensions and ratios.
- Main image source is real product photo.
- Product consistency across all generated images.
- Text language matches marketplace.
- No garbled text or tiny unreadable claims.
- No unsupported certification, rating, review, ranking, test, or performance claims.
- Desktop and mobile A+ modules are separately composed, not stretched copies.
- Contact sheet exists when practical.

## Incomplete Execution Handling

If fewer than 21 final images exist:

- Do not present the task as complete.
- Report the missing image IDs.
- Continue generating missing images when tools are available.
- Only stop early when the user explicitly requested fewer images or required source material is missing.
