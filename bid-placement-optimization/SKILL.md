# 竞价策略与广告位加价优化

## 目标
在保本约束下设置底价与广告位溢价，避免「动态竞价 × 广告位加价」叠乘失控。

## 核心公式
Bailing 11-17 口径（优先使用）：
```
保本 CPC = 单件广告前利润 × 预估转化率
# 例：利润 $8 × 转化 10% = $0.80
```
这是保本上限，不是盈利目标。要留利润，实际平均 CPC 还须低于它；转化率达不到预估时，上限下调。缺少利润或转化率时写「无数据」，不得套用其他产品的保本线。超过保本线只能作为有金额和期限的前期投资，须写明超多少、最多亏多少、观察多久。

与目标 ACoS 对照时，仍可用：
```
Max Bid ≈ Price × CVR × Target_ACoS
叠加后最高竞价 ≈ Base Bid × Dynamic Uplift × (1 + Placement Modifier)
```
框架和调价表必须同时写出基础出价、广告位加价、动态加价（如有）和叠加后最高竞价，不能只写基础出价。实际 CPC 通常低于最高应价，但要按叠加后最高竞价做风控。

## 步骤

### 1. 选动态竞价模式
| 模式 | 何时用 |
|------|--------|
| Dynamic - down only | 默认起步；控 ACoS；数据不足的新活动 |
| Dynamic - up and down | 已验证 Exact / 高转化词；要冲曝光时 |
| Fixed | 品牌防守、严格测 CPC、需要可复现实验时 |

路径建议：新活动 **down only** → 稳定 30–60 天且转化清晰 → 核心 Exact 再开 **up and down**。

### 2. 关键词/定向三桶调价（周更）
| 桶 | 动作 |
|----|------|
| Winners（数据充分且 ACoS≤目标） | 提价 **10–15%** |
| Losers（充分点击仍差） | 降价 10–20% 或暂停/否定 |
| Unknowns | **不调价** |

禁止：每天对同一词来回改价。

### 3. 广告位（Placement）流程
1. 打开 Placement 报告：对比 Top of Search / Rest of Search / Product Pages 的 spend、sales、CPC、CVR、ACoS。
2. 起始溢价 = 0，先攒数据（建议活动有较充分点击后再动）。
3. 决策：
   - ToS CVR 明显更好且 ACoS 达标 → 溢价 **+10–20%** 步进上调
   - ToS CPC 升、转化平 → 回调 10%
   - Product Pages 烧钱弱转化 → 溢价回到 0；考虑把商品流量拆到 PT 活动
4. Rest of Search：低 CPC 可接受时保持，勿因「不够顶」盲目砍。

### 4. 叠乘风控（必做）
若同时开启 up-and-down + 高 ToS 溢价：
- 用表格算出 Max Eligible Exposure
- 若潜在应价 > 2–3× Max Bid，先降 base 或降溢价，**一次只动一个杠杆**

### 5. 调价前检查（转化优先）
若 CVR 差：先查主图、价格、评论、优惠券、库存、配送承诺——**提价救不了差 Listing**。

### 6. 输出
- 本周调价清单：目标 | 旧价 | 新价 | 理由 | 预期观察期
- 广告位变更：活动 | ToS/PP 溢价旧→新
- 风控：Max Eligible Exposure 摘要

## 节奏
- 成熟活动：每周或每两周
- 上新/大促：每日盯盘，但非每日改价


## 踩坑记录
- 2026-11-17：只给基础出价并叠加首页加价和动态提高，导致 CPC 过高、成交达不到预期。见 SP Bulk 清单 v1.3。
