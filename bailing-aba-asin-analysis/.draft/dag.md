# DAG

```
[入参 file_path/asin/brand]
    │
    L1{S1 导入校验}  ★决策点（agent判断格式是否合法）
    │
    L2{S2-S4 run_pipeline.py}  确定性链（无决策点，脚本一次执行）
    │  S2: 按周聚合大盘vs ASIN指标
    │  S3: 逐关键词Gap + 词根tokenize+聚合
    │  S4: 四象限分类 + 广告结构 + 否定词
    │
    L3{S5 生成报告}  ★决策点（agent语义加工：解读数据、写洞察文案）
    │
    [HTML报告]
```

决策点：S1（格式校验）、S5（报告内容语义加工）
确定性链：S2-S4（纯计算，无业务判断）→ 打包 run_pipeline.py

并行分析：S2/S3/S4 有数据依赖（S3需要S2的聚合结果），必须串行 → 打包为脚本内部顺序执行
