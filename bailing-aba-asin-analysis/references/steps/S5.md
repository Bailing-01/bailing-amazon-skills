# 步骤 5：生成HTML报告

- **输入**：S2-S4 的 run_pipeline.py 输出 JSON
- **依赖**：S2-S4 加工完成
- **操作**：
  1. Read `linkfox-report-generator` 的 SKILL.md 和 references/analysis-layouts.md
  2. 从 JSON 数据中提取各章节所需数据，用 Python 预计算所有统计数字
  3. 按 analysis-layouts.md 组件库编写 HTML 片段（KPI Cards / Content Section / Chart Container / Data Table / Comparison Grid / SWOT Grid / Insight List）
  4. ECharts 图表：大盘趋势折线图、CTR/转化率对比图、词根展现柱状图、CTR/Conv Gap条形图、四象限散点图
  5. Write HTML 片段到文件
  6. 调 `linkfox-report-generator` 的 inject_report.py 注入模板
- **输出**：HTML 报告文件路径
- **用途**：交付给用户

报告章节：
- KPI概览（总展现/点击/购买/转化率/Gap）
- 大盘周度趋势（折线图+对比表）
- 逐关键词Gap分析（按展现量排序的明细表）
- 词根拆解（柱状图+Gap条形图+Top30明细表）
- 四象限分群（散点图+各象限明细表）
- 广告结构建议（6个Comparison Card+否定词清单）
- SWOT+行动项（Insight List）

每个含统计数字的 section 末尾加 data-source 标注。
