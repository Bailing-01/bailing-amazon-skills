# 步骤 2-4：确定性加工链（run_pipeline.py）

- **输入**：`file_path`（Excel路径）、`asin`（选填）、`brand`（选填）
- **依赖**：S1 导入校验通过
- **操作**：运行 `python scripts/run_pipeline.py '{"file_path":"...","asin":"...","brand":"..."}'`
- **输出**：JSON 含 weekly_trend / keyword_gaps / root_analysis / quadrant_summary / ad_structure / negation / q1-q4_keywords
- **用途**：全部数据供 S5 报告消费

run_pipeline.py 内部执行4步确定性加工：
- S2 大盘周度趋势：按Reporting Date分组计算大盘vs ASIN的CTR/转化率/加购率及Gap
- S3 逐关键词Gap+词根拆解：每个搜索查询的ASIN vs大盘CTR/转化率差距；tokenize后按ROOT_MAP聚合词根级指标
- S4 四象限分群+广告结构：按品牌词/竞品词/相关词/不相关词 + 转化率/CTR表现分Q1-Q4；输出6个广告活动建议+否定词清单

- **落盘**：`python scripts/response_io.py run --script scripts/run_pipeline.py --out-dir <session data dir> --label S2_S4_pipeline '{"file_path":"...","asin":"...","brand":"..."}'`
- **读取**：`python scripts/response_io.py read <文件> --fields "weekly_trend,keyword_gaps,root_analysis,quadrant_summary,ad_structure" --format jsonl --limit 5`
- **判定**：输出含 weekly_trend(数组) + keyword_gaps(数组≥50条) + root_analysis(数组) + quadrant_summary(对象4key)，字段数 ≥ 10 且跨步复用
