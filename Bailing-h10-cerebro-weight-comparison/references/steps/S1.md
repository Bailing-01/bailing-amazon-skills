# 步骤 1：读取Cerebro + 计算权重 + 输出Excel和JSON

- **输入**：`files`（ASIN→xlsx路径）、`rank_cutoff`（默认40）、`formula`（默认exponential）、`alpha`（默认0.15）、`power_exp`（默认1.5）
- **依赖**：无
- **操作**：运行 `scripts/run_pipeline.py`，传入 JSON 参数包
- **输出**：`weight-analysis-<ts>.json`（含summaries/top30/comparison/full_table）+ `weight-comparison-<ts>.xlsx`（4个Sheet格式化Excel）
- **用途**：供S2报告章节消费

### 调用示例

```bash
python scripts/run_pipeline.py '{"files": {"B0CQYTNNW7": "/path/a.xlsx", "B0D9HMJ252": "/path/b.xlsx"}, "rank_cutoff": 40, "formula": "exponential", "alpha": 0.15}'
```

### Excel 输出4个Sheet

1. **总权重对比**：ASIN × 总关键词/广告排名词/自然排名词/总搜索量/广告权重/自然权重/总权重/占比
2. **权重对比**：全量关键词级，每个关键词在三ASIN上的排名和权重
3. **各ASIN Top30**：每个ASIN权重最高的30个关键词
4. **关键词差距分析**：三方共有关键词按权重差距排序TOP50

### 权重公式

- **linear**：`W = SV × max(0, cutoff − Rank)`
- **exponential**（默认）：`W = SV × (cutoff−1) × e^(−α × (Rank−1))`
- **power**：`W = SV × (cutoff − Rank)^power_exp`

排名 ≥ cutoff 或无排名时权重为 0。`rank_cutoff` 按市场每页结果数设置，默认40。
