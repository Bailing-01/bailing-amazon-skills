# 步骤 2：生成 HTML 分析报告

- **输入**：S1 输出的 `weight-analysis-<ts>.json`（summaries / top30_per_asin / comparison_top50 / full_table_top100）
- **依赖**：S1
- **操作**：
  1. Read SKILL `linkfox-report-generator`（首次必读，获取组件规范）
  2. Read `references/analysis-layouts.md`（组件库）
  3. 从 JSON 提取数据，按报告章节结构写 HTML 片段到 `.fragment.html` 文件
  4. 调 `inject_report.py --content-file <fragment> --language zh --title <slug>` 生成最终 HTML
- **输出**：`<slug>-<ts>.html` 报告文件（绝对路径）
- **用途**：交付用户

### 报告章节（数据来源 → 组件）

1. **KPI概览**：summaries.total_weight / summaries.total_search_volume / common_keywords_count → KPI Cards
2. **整体权重对比**：summaries 三ASIN 广告/自然/总权重 → ECharts 柱状图 + Comparison Grid
3. **关键词覆盖分布**：summaries.kw_with_ad_rank / kw_with_org_rank / unique_keywords_count → ECharts 柱状图 + Data Table
4. **TOP20高权重关键词**：full_table_top100 前20条 → Data Table（三方排名+权重）
5. **核心关键词差距**：comparison_top50 前15条 → Data Table（差距排序+领先方）
6. **各ASIN TOP10**：top30_per_asin 每ASIN前10 → 3个 Data Table
7. **竞争研判**：基于上述数据的 SWOT Grid + Insight List

### 调用示例

```bash
python <report-generator>/scripts/inject_report.py \
  --content-file /path/to/weight-report.fragment.html \
  --language zh \
  --title weight-comparison-report
```

注意：`--title` 只允许英文字母和连字符（不能含数字）。
