# 六版／九版内容生成规范

<!-- workflow:v4 evidence-timeline causal-chain original-abc reshell-abc new-logic-abc belief-proof-action uncertainty pure-voiceover dynamic-variable-selection single-variable-lock nine-output visual-freedom -->

仅在用户明确确认生成后读取本文件。不得重新执行视频拆解。默认模式每条路线生成 A/B，共六版；用户明确要求九版时，才执行每条路线 A/B/C。两种模式都必须同时读取 `human-style-collaboration.md` 并通过人味互审。

## 原逻辑迭代

六版模式先建立一份共同基准脚本，再动态选择两个最值得测试且彼此独立的变量生成 A/B。九版模式选择三个独立变量生成 A/B/C。变量可以来自文案钩子、画面钩子、痛点切入、人群切入、留人节奏、案例呈现、机制解释、产品展示、信任背书、优惠、稀缺理由、CTA、口播者身份或内容形式，不得固定预设为开头、证明和购买理由。

- 默认 A/B 各标明一个唯一测试变量；九版再增加 C。
- 每版只实质改变该变量及其必须的语法衔接。
- 非测试区块沿用共同基准，只允许为语法衔接做最小修改，不得顺手重写。
- 同组变量不得重叠或互为同义改写；若无法隔离，重新选择变量。
- 保留原片的底层购买逻辑、目标人群、核心因果链、广告强度和转化方式。
- 迭代不是降调重写。保持原片的广告强度、节奏、镜头密度和直接转化意图。

## 原逻辑换壳

保留产品、目标人群、底层购买逻辑以及由该逻辑支撑的核心敌人、恐惧、反转、产品动作、结果图景和转化抓手。每版选择一种不同外壳，整体重做表现：

- 可更换人物表达、具体场景、故事角度、症状入口、叙事形式、文案表达、视觉体系、证明呈现和 CTA 画面。
- 可以大胆改变镜头、构图、动作、素材顺序、真实场景、信息可视化和视觉隐喻。
- 画面创新优先增强理解和可信度，不为炫技堆叠无关特效。
- 每版写明“保留的底层逻辑＋本版外壳方向”，并说明外壳与底层逻辑如何对应。
- A/B/C 必须是三种明显不同的完整表现系统，而不是只换演员、地点或同义词。
- 抽掉人物、场景和措辞后，各版必须仍能还原为原视频同一条购买因果链。

## 新底层逻辑

保持产品和目标人群不变，但必须为每版选择一个新的根本逻辑。根本逻辑是整条内容为什么成立的组织方式，不是换场景、换话术或换一个产品卖点。

每版都要重新匹配：

1. 开头为什么能让人停下；
2. 用户为什么觉得内容与自己有关；
3. 用户为什么相信产品有效；
4. 用户为什么愿意现在行动；
5. 文案、画面和证明如何围绕同一个逻辑服务。

只更换人物、场景、故事、标题、同义词、口吻或单个证明素材，不算换底层逻辑。

执行换路径：

- 每版用完整因果链写明“原底层逻辑 → 新底层逻辑”，不能只写一个卖点或标题。
- 更换观众相信产品并购买的根本理由；围绕新路径重建开头、相关性、痛点、机制、证明、信任和行动理由。
- 固定产品和目标人群；人物、场景、叙事形式、素材体系、镜头和画面可以大胆调整。
- 保持强广告属性、合理基准时长、充分证明强度和明确下单动作。
- 风险逆转、专家诊断、相似用户代入只是候选路径，必须根据原视频与产品动态选择，不得固定套用。
- 不得把强转化广告改成科普课程、方法论教学、自我记录实验、习惯养成计划、理性劝退或弱 CTA 内容，除非用户明确要求。

## Hook 对比

每版都保留原始开头 Hook 作为参照，并并列输出优化 Hook、关键变化和预期留人作用。优化 Hook 必须继续服务原痛点、受众与该版购买路径。若唯一测试变量不是 Hook，写明“Hook 保持不变”，并让原 Hook 与优化 Hook 逐字一致；不得为了显得有变化而污染单变量测试。

若多个视频开头相同，标记为同创意或重复素材，并说明是否值得分别测试。不得把同一个母版的重复视频伪装成独立 Hook 方向。

## 距离审计

交付前逐项检查。六版模式检查三条路线各 A/B；九版模式检查三条路线各 A/B/C：

1. 迭代组是否为每版动态选择独立变量，且每版只有一个变量发生实质变化；
2. 换壳组是否保留同一底层购买逻辑，但形成明显不同的完整表现；
3. 新底层逻辑组是否真正更换购买路径，而不是只换开头、顺序、人物或话术；
4. 六版或九版是否保持产品销售强度、证明责任和完整 CTA；
5. 换壳与换逻辑版的画面是否服务理解和可信度，而不是无意义炫技；
6. 本轮所有最终口播是否互不重复；
7. 若任一项失败，先重写对应版本，不得交付。

## 脚本约束

- 每版只设一个主测试变量，其余重要变量尽量稳定。
- 时长、语速和镜头密度以原视频为基线，偏差超过 20% 时说明原因。
- 每段使用：`开始秒｜结束秒｜中文口播｜画面内容与动作｜画面目的`。
- 画面目的只能写：留人、解释、证明、信任或下单。
- 本轮六版或九版必须存在实质差异。
- `final_voiceover` 必须与分段 `voiceover` 顺序拼接后逐字一致，只去掉时间码、动作和分析。
