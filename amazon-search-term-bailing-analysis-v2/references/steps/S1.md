# S1: 读取Excel

## 输入
- `excel_path`：用户提供的 Excel 文件路径

## 依赖
- 无（流水线第一步）

## 操作
1. 运行 `scripts/run_analysis.py --excel <path> --step extract`
2. 脚本用 openpyxl 加载 Excel，读取名为「商品推广 搜索词展示量份额 报告」的 sheet
3. 定义 `to_float(v)` 处理类型转换（部分值为字符串或 None，统一转 float）
4. 按列索引映射（0-indexed）提取全部数据行：

| 常量 | 列号 | 含义 |
|------|------|------|
| `COL_MARKET_IMP` | 0 | 搜索词总展示量 |
| `COL_COUNTRY` | 2 | 国家/地区 |
| `COL_SEARCH_TERM` | 3 | 客户搜索词 |
| `COL_RANK` | 4 | 搜索词展示量排名 |
| `COL_SHARE` | 5 | 搜索词展示份额 |
| `COL_TARGET` | 6 | 投放 |
| `COL_MATCH_TYPE` | 7 | 匹配类型 |
| `COL_PORTFOLIO` | 8 | 广告组合名称 |
| `COL_CAMPAIGN` | 9 | 广告活动名称 |
| `COL_AD_GROUP` | 10 | 广告组名称 |
| `COL_CURRENCY` | 11 | 货币 |
| `COL_CLICKS` | 12 | 点击量 |
| `COL_IMPRESSIONS` | 13 | 展示量 |
| `COL_SPEND` | 15 | 花费 |
| `COL_ORDERS` | 17 | 7天总订单数 |
| `COL_SALES` | 18 | 7天总销售额 |

5. 按广告组合(Portfolio) → 搜索词聚合，同一搜索词跨活动/匹配类型的行合并求和
6. 计算派生指标：CPC=花费/点击, CVR=订单/点击, CPA=花费/订单, avg_rank, avg_share, market_total=展示量/份额
7. 输出 JSON，落盘到 session data 目录

## 输出
- `data/extracted_data.json`：按广告组合分组的搜索词聚合数据（含原始指标 + 派生指标）

## 用途
- 供 S2（结构提取）和 S3（搜索词聚合）并行消费
