## 这个 Skill 做什么

亚马逊 ABA 品牌视图搜索查询绩效报告深度诊断：大盘 vs 品牌全链路漏斗桑基图、帕累托分析、头部关键词差距透视。  
还包括长尾词分类归组、价格价位段分析、多周动态趋势和关键词标签化表格；CSV 输入，输出 HTML 报告 + CSV 标签表。单 ASIN 的 ABA 分析走 bailing-aba-asin-analysis。

## 怎么用

触发词：ABA品牌分析、品牌视图搜索词绩效、搜索查询绩效报告、品牌ABA诊断、ABA brand view、品牌搜索词报告；或直接说“分析这份品牌ABA报表”

安装：把本文件夹复制到你的 Agent skills 目录即可（完整说明见 `SKILL.md`）。

```bash
git clone https://github.com/Bailing-01/bailing-amazon-skills.git
# Claude Code；Codex / Hermes 等换成对应的 skills 目录
cp -r bailing-amazon-skills/skills/bailing-aba-brand-analysis ~/.claude/skills/
```
