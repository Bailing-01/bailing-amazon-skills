# ABA 品牌视图搜索查询绩效深度诊断

输入ABA品牌视图搜索查询绩效CSV报告（1周或多周），输出HTML诊断报告 + 关键词标签化CSV表格。

## 适用与不适用

**适用**：ABA品牌视图"搜索查询绩效"CSV报告的深度诊断——漏斗分析、价位段分析、多周趋势、关键词标签化。

**不适用**：单ASIN的ABA搜索词份额报告（走`bailing-aba-asin-analysis`）；单条关键词查询（走ABA查询工具）；非ABA格式报表。

## 输入参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| file_paths | string | 无（必填） | 1-4个CSV文件路径，逗号分隔。最新周放第一个 |
| brand | string | 无 | 品牌名（从CSV元信息自动检测，选填） |

## 执行编排

L1{S1} → L2{S2-S4} → L3{S5}

S1是数据导入校验；S2-S4是确定性加工链（由run_pipeline.py一次执行）；S5是报告生成（handoff linkfox-report-generator）。

### 流水线

| 步骤 | 做什么 | 调用 | 依赖 | 用途 | 详情 |
|------|--------|------|------|------|------|
| S1 导入校验 | 读取CSV确认字段结构与周次 | agent 判断 | 无 | 传file_paths给S2 | `references/steps/S1.md` |
| S2-S4 数据加工 | 漏斗汇总+帕累托+头部差距+长尾分类+价位段+多周趋势+标签表，一次执行 | `scripts/run_pipeline.py` | S1 | 全部数据供S5报告消费 | `references/steps/S2-S4.md` |
| S5 生成报告 | 基于加工数据生成HTML诊断报告 | `linkfox-report-generator` | S2-S4 | 交付给用户 | `references/steps/S5.md` |

## 报告产物

报告章节与数据来源（样式由 linkfox-report-generator 接管）：

- **KPI概览**：最新一周核心指标卡片，来自S2汇总
- **一、大盘vs品牌漏斗对比**：对比表+品牌桑基图+大盘vs品牌对比桑基图+漏斗诊断，来自S2
- **二、帕累托分析**：头部vs长尾词对比表，来自S2
- **三、头部关键词差距分析与长尾分类**：头部10词桑基图+差距明细表+长尾分类桑基图+分类表，来自S3
- **四、价格价位段深度分析**：5价位段对比表+柱状折线图+各段大盘vs品牌卡片+战略总结，来自S3
- **五、多周动态趋势**（多周时）：周度指标表+漏斗率层积图+份额柱状图+关键词堆叠图+关键词流动，来自S4
- **六、综合研判与行动项**：SWOT+优先级行动项，来自S2-S4数据由agent语义加工
- **附：关键词标签化CSV**：31列标签表，来自S2

元信息：生成时间/数据周期/品牌/搜索词数/参数快照。

> ⚠ 生成报告必须先阅读 SKILL `linkfox-report-generator` 并遵循其规范：样式、排版、md/html 导出、元信息块统统由它负责，本 skill 不得复制报告样式或 html 模板。

## 已知局限

- 品牌量由"大盘总量 × 品牌份额%"逐行计算汇总，存在整数取整误差
- 价位段分界基于大盘点击价格中位数，可能因个别异常值偏移
- 多周趋势需至少2周数据，4周效果最佳
- 标签阈值（份额高/中/低、率Gap高/中/低）为预定义，可能需按品类调整
