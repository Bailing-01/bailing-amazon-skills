# 步骤 5：生成报告

- **输入**：S2-S4 输出的 JSON 数据
- **依赖**：S2-S4 加工完成
- **操作**：agent 按 SKILL.md 报告产物章节，用 linkfox-report-generator 的组件库写 HTML 片段，调 inject_report.py 生成最终 HTML
- **输出**：HTML 报告路径 + CSV 标签表路径
- **用途**：交付给用户

关键报告组件：
- KPI Cards（最新周核心指标）
- 桑基图 ×4（品牌漏斗 + 大盘vs品牌对比 + 头部关键词流向 + 长尾分类流向）
- Data Table（对比表、差距明细表、价位段表、周度趋势表）
- Comparison Grid（各价位段大盘vs品牌卡片）
- 堆叠面积图（4周漏斗率层积趋势）
- SWOT Grid + Insight List（综合研判）

> ⚠ 生成报告必须先阅读 SKILL `linkfox-report-generator` 并遵循其规范。
