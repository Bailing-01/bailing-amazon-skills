# 步骤 2-4：确定性加工链（run_pipeline.py）

- **输入**：`file_paths`（逗号分隔的CSV路径）、`brand`（选填）
- **依赖**：S1 导入校验通过
- **操作**：运行 `python scripts/run_pipeline.py '{"file_paths":"path1,path2","brand":"YTDB"}'`
- **输出**：JSON 含 overview / pareto / head_gaps / tail_categories / price_segments / weekly_trend / keyword_tags
- **用途**：全部数据供 S5 报告消费

run_pipeline.py 内部执行4步确定性加工：
- S2 漏斗汇总+帕累托：逐行计算品牌量（大盘×份额%），汇总大盘vs品牌漏斗，按品牌曝光降序做帕累托80/20切分
- S3 头部差距+长尾分类+价位段：头部10词逐词Gap分析；长尾按搜索意图6分类归组；按大盘价格中位数分5价位段
- S4 多周趋势+标签表：多周时按周汇总漏斗率和份额变化；对最新周每条搜索词打31列标签输出CSV

- **落盘**：`python scripts/response_io.py run --script scripts/run_pipeline.py --out-dir <session data dir> --label S2_S4_pipeline '{"file_paths":"...","brand":"..."}'`
- **读取**：`python scripts/response_io.py read <文件> --fields "overview,pareto,head_gaps" --format jsonl --limit 5`
- **判定**：输出含 overview(对象) + pareto(对象) + head_gaps(数组≥10) + tail_categories(数组≥5) + price_segments(数组=5) + keyword_tags(CSV路径)，字段数 ≥ 10
