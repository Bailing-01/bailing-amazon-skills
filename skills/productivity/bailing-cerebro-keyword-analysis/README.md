## 这个 Skill 做什么

H10 Cerebro 反查报表关键词分析：从关键词数据中自动发现产品类目与属性标签。  
按流量等级 / 蓝海度 / ABA 垄断 / 相关性四维度拆分，输出 V4.1 CSV + 四维度总结报告。单维度查询不走这个 Skill。

## 怎么用

触发词：Cerebro 分析、关键词拆分、反查报表分析、关键词四维度评估；或直接说“帮我分析这份反查报表”

安装：把本文件夹复制到你的 Agent skills 目录即可（完整说明见 `SKILL.md`）。

```bash
git clone https://github.com/Bailing-01/bailing-amazon-skills.git
# Claude Code；Codex / Hermes 等换成对应的 skills 目录
cp -r bailing-amazon-skills/skills/productivity/bailing-cerebro-keyword-analysis ~/.claude/skills/
```
