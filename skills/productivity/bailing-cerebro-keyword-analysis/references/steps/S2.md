# S2: V3 五步评估

## 输入
- S1 输出的 rows

## 依赖
- S1

## 操作
1. **词根拆解**：每词拆为核心/上位/属性/弱相关四类，统计词根频次
2. **流量分层**：vol≥5000 大词 / 1000-5000 中词 / <1000 小词
3. **SABC 分级**：S=大词+高IQ+排名差 / A=中词+有排名 / B=小词+有IQ / C=品牌词+西语 / D=弱相关
4. **CPR+竞争度**：CPR 分桶(低/中/高/极高) + 竞争度(低/中/高/红海) + 优先级得分
5. **Top N 排序**：按优先级降序，输出 Top 30 S级 / Top 50 C级 / Top 100 B级

## 输出
- V3 CSV: 19 列（序号/关键词/核心词根/上位词/属性词/弱相关/搜索量/CPR/竞争度/广告ASIN数/竞品数/IQ得分/自然排名/广告排名/推荐行动/流量分级/广告分级/综合优先级/备注）

## 用途
供 S4 输出 + 报告生成消费
