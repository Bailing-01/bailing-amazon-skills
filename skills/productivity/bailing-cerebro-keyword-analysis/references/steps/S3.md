# S3: V4.1 动态属性发现 + 4 维度评估

## 输入
- S1 输出的 rows

## 依赖
- S1

## 操作

### Phase 1: 动态属性发现
1. **词频统计**：全部关键词 tokenize，统计 token 频次
2. **核心词识别**：频次 Top 20 且出现在 ≥5 个不同关键词中 = 核心词
3. **属性词发现**：非核心词的高频 token（频次 ≥3）= 潜在属性标签
4. **维度映射**：用通用种子词库 + 上下文启发式将属性词映射到 11 维 Cosmo 框架
   - 通用种子：跨品类通用映射（如 women→AUDIENCE, gift→PURCHASE_CONTEXT, korean→ORIGIN）
   - 上下文启发式：属性词与核心词的共现关系辅助归类
5. **动态属性树**：种子词 + 发现词合并 → 该次分析的专属属性树 JSON

### Phase 2: 打标 + 数值评估
1. 用动态属性树对每词打 11 维标签（多词 pattern 用 in 匹配，单词用 token boundary）
2. V3 原分类（复用 V3 SABC 逻辑）
3. 4 维度数值评估：
   - 流量等级 S/A/B/C/D（vol ≥50k/10k/5k/1k/<1k）
   - 蓝海度 5 档（竞品 <500/500-1k/1k-5k/5k-10k/≥10k）
   - 准入难度 6 档（ABA 转化份额 >70%/50-70%/30-50%/15-30%/<15%/无数据）
   - 相关性等级（竞品表现得分 ≥8/≥6/≥4/<4/无数据）
4. 品牌词护城河过滤（Pitfall #16）
5. 推荐行动：4 维度反推

## 输出
- V4.1 CSV (EN): 23 列
- V4.1 CSV (ZH): 23 列
- 统计 JSON: 含动态属性树 + 维度命中 + 行动分布 + Top金矿词

供 S4 输出 + 报告生成消费
