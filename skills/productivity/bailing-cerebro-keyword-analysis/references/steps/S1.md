# S1: 读取 xlsx + 解析列

## 输入
- xlsx_path: Cerebro 反查 xlsx 文件路径

## 依赖
- 无（流水线起点）

## 操作
1. 用 openpyxl read_only 模式加载 xlsx
2. 第 1 行为表头（34 列），跳过
3. 逐行读取数据，提取关键列：关键词(0) / ABA转化份额(2) / 销量(3,5) / IQ(4) / 广告ASIN(10) / 竞品(11) / CPR(12) / 自然排名(14,27) / 竞品表现(31)
4. 空值/`-`统一转 0（数值列）

## 输出
- `rows`: list of list，每行 34 列原始数据

## 用途
供 S2（V3 分析）和 S3（V4.1 属性打标）并行消费
