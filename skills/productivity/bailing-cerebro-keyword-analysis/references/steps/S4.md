# S4: 输出 + 报告触发

## 输入
- S2 V3 分析结果
- S3 V4.1 分析结果 + 统计 JSON

## 依赖
- S2, S3

## 操作
1. 写 V3 CSV（utf-8-sig，csv.writer QUOTE_MINIMAL）
2. 写 V4.1 CSV 英文版 + 中文版
3. 写统计 JSON
4. CSV 列数验证（Pitfall #9 防错位）
5. 属性树覆盖检查（11 维命中均 > 0）
6. 品牌词过滤验证（is_brand=True → action=否定）
7. agent 拿到统计 JSON 后调 `linkfox-report-generator` 生成 HTML

## 输出
- `cerebro-analysis-{ASIN}.csv`
- `keyword-cosmo-attribute-{ASIN}-v41.csv`
- `keyword-cosmo-attribute-{ASIN}-v41-zh.csv`
- `analysis-stats-{ASIN}.json`

## 用途
最终交付物 + 报告生成输入
