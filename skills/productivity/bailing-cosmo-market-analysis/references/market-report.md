# COSMO 市场报告口径与章节

## 口径

| 项 | 定义 |
|----|------|
| 搜索量空值 | 按 0 |
| 属性 `-` / 空 | 未标注，不计入该维 |
| 多标签 `a\|b` | 维度汇总时 **等分** 该词搜索量；报告注明「多标签等分」 |
| 头部 | 按搜索量降序，取前 **4%** 词（帕雷托视角的头部样本） |
| 长尾 | 按搜索量升序侧，取词量 **后 80%**（低量长尾） |
| 填充率 | 该维至少有一个有效标签的词数 / 总词数 |
| 低填充警告 | 填充率 **&lt; 5%** →「不适合作为主战场」 |
| 蓝海窗口 | 蓝海度含「蓝海/温和」（及「一般」弱保留），排除「激烈/极激烈」 |

## HTML 章节

1. **总览 KPI** — 词数、总搜索量、人群覆盖率、P50/P90、头部贡献、可用维数
2. **数学/科学洞察** — 自动结论列表（禁止编造）
3. **头部 vs 长尾** — 各关键维属性条形图
4. **属性维度流量副表** — 13 个 COSMO 维，每维 Top 流量条 + 表（全景视图）
5. **产品深耕分析** — 按填充率动态取 Top 5 维度下钻：集中度/进度条/全标签/跨维共现
6. **维度交叉** — 人群×功效、形态×风格、痛点×功效、价值×形态
7. **蓝海 × 搜索量** — 高需求低竞争候选词表

## Excel Sheet

| Sheet | 内容 |
|-------|------|
| 说明 | 口径、KPI、填充率 |
| 词明细 | 原表字段 + AutoFilter |
| 维度汇总 | 全维 tag×词数/搜索量/占比 |
| 副表汇总 | 按人群/价值/功效/形态等分段 |
| 人群汇总 / 价值修饰 / 功效 / 形态 / 风格 / 痛点 / 产地 | 单维明细 |
| 洞察 | 自动文字结论 |
| 交叉共现 | 高量标签对 |
| 蓝海窗口 | 候选词 |

## 口头 5 条硬结论模板

优先覆盖：① 头部集中度 ② 主分析轴（高填充维）③ 某维 Top 标签流量 ④ 一条高量交叉 ⑤ 蓝海窗口或低填充警告。数字必须来自当次运行结果。
