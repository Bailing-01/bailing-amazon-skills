## 这个 Skill 做什么

田哥哥 TikTok 视频工作流 4.0：TK 内容生产总编排。  
从公开账号、单条视频、本地视频或 account_manifest / breakdown_bundle / script_bundle 任一节点开始、继续或恢复任务，串起素材拆解、素材沉淀、新脚本生成和飞书同步。

## 怎么用

触发词：从 TikTok/TK 账号、视频或中间产物开始 / 继续 / 恢复完整 TK 内容生产任务（拆解、沉淀、新脚本、飞书同步）
